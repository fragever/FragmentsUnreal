# Security policy

## Supported versions

The current v1.x release line is supported for security fixes. Older revisions
may not receive fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory workflow once the repository is public, or contact the
maintainers through the private security contact configured in the repository.

Include the affected version or commit, platform, Unreal Engine version,
reproduction steps, impact, and a safe proof of concept. Do not include
proprietary BIM files, credentials, personal data, or customer information.
